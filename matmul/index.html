each row of A hits B on its own: ai is a 1×n matrix and ai·B is its own little matmul. stacking the results vertically rebuilds the product — A@B = vstack(a₁@B, …, a_m@B).

math thinks in column vectors: y = A·x. code usually stores x as a row, so the same product is written y = x·Aᵀ. transposing flips the whole equation — (A·x)ᵀ = xᵀ·Aᵀ — watch each entry reflect across the diagonal: same numbers, laid on their side. (here x is the first column of B.)

attention is two matmuls. routing: S = Q·Kᵀ dots every query row with every key row — the transpose trick turns a stack of rows into an all-pairs dot grid — and softmax makes each score row a set of weights. mixing: out = W·V is the row-stack view — each output token is a weighted blend of the value rows, and its color is the blend of the tokens it read from.
